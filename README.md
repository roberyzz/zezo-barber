 ZezoBarber

Site institucional responsivo desenvolvido para uma barbearia fictícia, com foco em uma apresentação moderna, elegante e voltada para experiência do usuário.

 Site

 **[Acessar o ZezoBarber](https://roberyzz.github.io/zezo-barber/)**

 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Google Fonts
* GitHub Pages

 Funcionalidades

* Design responsivo para computador e celular
* Menu de navegação
* Página inicial com seção de destaque
* Seções de serviços, sobre, galeria, depoimentos e contato
* Botões de agendamento
* Animações e efeitos de interação
* Layout adaptável a diferentes tamanhos de tela

 Desenvolvimento

O projeto foi desenvolvido como parte dos meus estudos em **Engenharia de Software**, utilizando IA como ferramenta de apoio durante o processo de desenvolvimento, aprendizado e resolução de problemas.
